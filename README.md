# YouTube Ad Yt-Music Skipper 🚀

A lightweight Chrome extension built for **educational and research purposes** to demonstrate Chrome extension architecture, content scripts, and DOM manipulation techniques.

## ⚠️ Educational Purpose Disclaimer
This repository and its source code are published strictly for **educational, academic, and research purposes**. The intent is to study how browser extensions interact with web page Document Object Models (DOM), execute content scripts, and manage asynchronous browser events. The author does not endorse circumventing platform terms of service or blocking advertisements on commercial streaming services. Users are solely responsible for ensuring their use of this script complies with the terms and policies of the respective platforms.

## Features
- Supports both YouTube and YouTube Music.
- Lightweight implementation using Manifest V3.
- Periodic DOM checks using clean, vanilla JavaScript.
- Automated handling of standard player overlay elements.

## Installation (For Development & Study)

1. Clone or download this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the folder containing these project files.
